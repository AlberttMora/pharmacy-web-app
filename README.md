# Pharmacy Web App

Course project for Web Development III. The requirement was a basic JOptionPane app — independently implemented with Spring Boot, JPA, MySQL, and WebSocket real-time updates instead.

## Features

- Patient and medication management with full CRUD
- Many-to-many relationship between patients and medications
- Real-time notifications using WebSocket and STOMP
- MySQL persistence with JPA and Hibernate
- Referential integrity handled on delete to avoid orphaned records

## Tech Stack

- Java
- Spring Boot
- JPA / Hibernate
- MySQL
- WebSocket (STOMP)
- Maven

## Requirements

- Java 11+
- MySQL 8+
- Configure `application.properties` with your database credentials before running
